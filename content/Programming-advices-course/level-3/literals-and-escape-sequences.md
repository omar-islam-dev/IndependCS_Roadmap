# Literals
Literals are data used for representing fixed values.
They can be used directly in the code.
- For example:
	5, 3.5, 'b', "Mohammed",..etc.

Here, 5, 3.5, 'b', "Mohammed" 
are literals. Why? 
- You cannot assign different values to these terms.

## Literal Types:
1. Integer Literals:
	1. decimal (base 10)
	2. octal (base 8)
	3. hexadecimal (base 16)

Decimal: 0, -9, 22 etc
Octal: 021, 077,033 etc
Hexadecimal: 0x7f, 0x20, 0x521 etc

In C++ programming, **octal** starts with a **0**, and hexadecimal starts with a **0x**. 2. Floating-Point Literals: 13.5, 1.99, -8.07
3. Characters Literals: A, b, z, $,#
4. Escape Sequences Literals: \n, it will be explained next.
