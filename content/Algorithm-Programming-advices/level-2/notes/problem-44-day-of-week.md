
# Problem
Write a program to ask the user to **enter**:
- Day

Then print the as follows:
- 1 print Sunday
- 2 print Monday
- 3 print Tuesday
- 4 print Wednesday
- 5 print Thursday
- 6 Print Friday 
- 7 Print Saturday
- Otherwise print "Wrong Day" and ask the user to enter the day again.
