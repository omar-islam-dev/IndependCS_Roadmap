# Problem

Write a program to ask the user to enter:
Age
If age is between 18 and 45 print "Valid Age" otherwise print "Invalid Age"

---
# Solution
1. ask the user to enter the age
2. result = (age >=  18 and age <= 45)
3. if result is true 
	1. print "valid age"
	  else
	2. print "invalid age"
