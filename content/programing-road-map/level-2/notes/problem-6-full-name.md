# Problem
Write a program to ask the user to enter:
First Name
Last Name
Then Print Full Name on screen.

similar to [[problem-1-print-your-name]] and [[problem-2-print-the-entered-name]]

---

# Solution
## old:

1. ask the  user to enter his first name
2. ask the user to enter his last name
3. input = (first name + last name)
4. print input
   
## the more accurate one:
1. ask the  user to enter his first name
2. ask the user to enter his last name
3. input = (first name + " "+last name)
4. print input
   
   
   why we added " " ? 
   because if we combined first and last name variables with out double quotations the out put would be fistnamelastname as an example.
